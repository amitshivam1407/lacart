# LACART

Lookahead CBF-CLF safety filter for unicycle robots.
Team LACART: Pedro Lopes, Amit Shivam, Luís Tiago Paiva
(UP2SPEED, FEUP, U.Porto, SYSTEC). TrustRobotics Challenge 2026, CSAW'26 Europe.

Live demo: https://amitshivam1407.github.io/lacart/

The page has three modes: a single obstacle, track 1 and an 8-shape track.
You can change the lookahead ℓ, margin and CBF gain α and watch the robot's path.

Note: this is an illustrative browser re-implementation of the controller.
It has no CLF slack, no track-limit barriers, no vision delay and no body model,
so lap times and clearances differ from the reported simulation and hardware results.
